A webhook is an HTTP request that one system sends to another when an event happens, such as a new lead being created. The receiving server should verify a secret or signature to confirm the request is genuine, then respond quickly with a 200 status code. Slow work should run in the background. REST APIs are used when our code needs to ask another system for data, and they usually require an API key or token sent in a request header. Failed calls should be retried with a delay and logged.
